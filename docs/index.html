01 / SYSTEM

A language core.
A measured system.

The model, its tools, and its decision policy are assessed separately so each claimed gain has a clear source.

01

Original text architecture

Causal state-mixing blocks and grouped-query attention define a 4.075B-parameter research configuration. Only the tiny structural checkpoint has been trained.

02

Audited tool harness

Local memory and retrieval, declarative skills, optional web search, and bounded tool calls supply context and verifiable actions.

03

Decision dynamics

A separate, paper-inspired stochastic controller is being tested against deterministic policies under matched task and energy budgets.

03 / HYPOTHESIS

Can dynamics improve decisions?

The project investigates whether finite-time stochastic dynamics can improve tool selection and task completion beyond equally sized deterministic controllers. The motivating thermodynamic computing paper demonstrated a different system; translating its principle into a text agent is an open experiment.
